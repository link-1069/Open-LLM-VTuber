# Electron 数字人自动接入与实时切流设计

日期：2026-08-12
状态：已确认

## 目标

Electron 每次启动后自动发现活动数字人推流、验证 SRS 可达性并预加载真实 WHEP 画面。用户不再输入地址或点击按钮；首帧完成 Three.js 渲染后才显示数字人，并在展示期间持续发现和无缝切换新的活动流。

## 固定连接

- 活动流发现：`GET http://localhost:8500/api/active-streams`。
- 活动流字段：响应中的 `stream.av_stream_id`。
- WHEP 地址：`http://127.0.0.1:1985/rtc/v1/whep/?app=live&stream=<encoded id>`。
- 连接测试：`GET http://127.0.0.1:1985/api/v1` 返回 HTTP 2xx。该测试只证明 SRS HTTP 服务可达，不证明 WHEP 或视频可用。
- ID 请求与连接测试分别在 3 秒后超时。

## 启动与检测循环

1. Electron 就绪后立即显示纯状态自动接入窗口，同时在后台启动 Python 服务和隐藏的主展示窗口。
2. 每次进入自动接入（应用启动、真实流故障或用户主动重新检测）时，把配置中的 `whep_url` 写为空字符串并更新 `last_updated`。清除失败需要展示错误，但不得使用旧地址，也不得停止检测。
3. 页面加载后立即开始第一轮，之后每 1 秒触发一次。上一轮尚未结束时跳过当前节拍；跳过不增加轮次编号，也不允许请求重叠。
4. 每轮先获取有效活动流 ID，再测试由该 ID 生成的 SRS 地址。两个结果必须属于同一轮。
5. 任意失败都在自动接入窗口显示阶段、原因和下一轮提示，并持续无限重试，直到成功或用户关闭应用。

## 初次画面启动

1. 第一次同轮双成功后立即保存 WHEP 地址；保存失败则下一节拍重新执行完整检测。
2. 隐藏主窗口使用该地址预加载真实 WHEP：建连最多 10 秒，建连后画面等待最多 2 分钟。
3. 画面就绪要求视频已解码出有效尺寸的帧，并且 Three.js 至少成功渲染该视频一次。
4. 画面就绪后才显示主窗口并隐藏自动接入窗口。打开失败时清空地址并恢复完整检测。
5. WHEP、画面等待或渲染失败时清空地址，将该 ID 冷却 5 秒，然后恢复检测。冷却只存在于当前应用进程。

## 首帧等待期间的发现

- 仍每秒获取活动流 ID，但相同 ID 不重复连接测试或重建 WHEP。
- 空结果或发现失败不取消正在启动的候选流。
- 不同的新 ID 必须先通过自己的连接测试；成功后才取消旧候选并启动新候选，失败则继续等待旧候选。
- 候选等待期间再次出现更新 ID 时，以最新通过连接测试的 ID 为候选。

## 主展示期间的实时替换

- 主窗口正常显示时继续每秒发现活动流。发现失败、空结果或候选失败只写开发者日志，不打断当前画面。
- 不同的新 ID 通过连接测试后在后台启动候选流。当前画面保持显示。
- 新候选完成画面就绪后，先保存新地址；保存成功后才无缝切换画面并关闭旧流。
- 候选保存失败时保留当前流和已就绪候选，每秒继续发现并重试保存。
- 发现结果重新回到当前显示 ID 时，立即取消其他候选。

## 故障恢复

- 当前流进入 `failed`、`closed` 或媒体轨道结束时立即恢复；`disconnected` 持续 3 秒仍未恢复才视为故障。
- 当前流故障后隐藏主窗口、显示自动接入窗口、清空配置并冷却失败 ID。
- 如果已有其他候选流，保留其启动过程；候选画面就绪并保存成功后可直接恢复展示。
- Python WebSocket 不属于画面接入门槛，失败时只在后台按现有逻辑重连，不显示用户提示。

## 窗口与进度界面

- 自动接入窗口不包含 URL 输入框或手动按钮。
- 显示当前检测轮次、活动流 ID 状态与完整 ID、SRS 连接测试状态、失败原因、下一轮提示、WHEP 建连倒计时和画面等待倒计时。
- 主窗口右键菜单项改为“重新检测连接”，触发后结束当前展示并重新进入自动接入。
- 用户主动关闭自动接入窗口或主展示窗口时退出整个应用，并停止检测与 Python 子进程。
- 保留现有主窗口位置、尺寸和控制面板行为。

## 实现结构

- `AutoConnectController` 是检测与持久化编排模块；其公共接口负责启动、停止和主动重新检测。
- `DigitalHumanStreamManager` 是双流生命周期模块；其公共接口负责准备候选、激活候选、取消候选和关闭流。
- 主展示 renderer 长期持有上述模块。主进程只协调自动接入窗口与主展示窗口的显隐、退出和 IPC。
- 自动接入 renderer 只消费进度快照并呈现，不持有检测状态。

## 测试缝隙

- `AutoConnectController` 公共接口：检测节拍、请求超时、同轮门控、冷却、配置生命周期、首次展示和后台替换。
- `DigitalHumanStreamManager` 公共接口：WHEP/首帧超时、Three.js 首次渲染、双槽切换、候选取消和断线宽限。
- Electron IPC/窗口集成：启动并行、隐藏预加载、进度转发、重新检测以及现有窗口控制回归。
